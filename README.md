# Receiptr

## What is it?
Receiptr is a web app for saving purchases and keeping track of return deadlines and warranties.

## Features
- Save purchase information
- Search and edit receipts
- Track return deadlines
- Track warranties
- Return-risk dashboard
- Mark purchases as returned
- Purchase insights

## How to use it
Add the information about a purchase and Receiptr will save it and show its return and warranty information.

## What I learned
I learned more about JavaScript, localStorage, working with dates, arrays, loops, and updating HTML using JavaScript.
